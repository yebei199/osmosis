# v0.2.6

**编译时放歌不再卡。** 以前电脑 CPU 一忙（比如编译项目），桌面版放歌就一卡一卡的：往声卡送声音的那条线程只有普通优先级，要和编译进程抢 CPU，路上还会等几把和界面共用的锁。现在这条线程开流时会向系统申请实时优先级，路上也不再等任何锁。在所有核都占满的情况下连续放两分钟，欠载从改动前的每分钟约 590 次降到 0 次。申请不到实时优先级时，日志里会写一行警告，播放照常。见 [#192](https://github.com/yebei199/osmosis/issues/192)。

**播放器内部换了一层。** 换歌、清空、音量这一层不再用声音库自带的播放器，改成自己写的、不会卡住送声线程的版本。手机和电脑共用这一层。电脑上点歌、暂停、继续、音量、拖进度、自动下一首都验过；这一版没有在手机上做过实机验证，手机上播放如果有异常请反馈。

测试侧：新增一份满载回归检查（`test/audio-rt-load.sh`），验收脚本加上了音频模块那一组测试。

本版发布桌面 Linux x86_64 产物、Android arm64 APK 和服务端 arm64 镜像（服务端无改动）。安装与部署流程见 [release/README.md](https://github.com/yebei199/osmosis/blob/v0.2.6/release/README.md)。
