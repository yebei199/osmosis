# v0.2.7

**打开就是音乐。** 去掉了原先的外层入口和首页，音乐功能统一放在一层导航里，找歌曲、歌单、电台、播放队列和设置都可以直接进入，少绕一层。

**窗口宽了，列表也用得上。** 歌曲列表会随窗口宽度调整列的分配，宽屏能展开更多信息；设置和个人页在宽屏上居中并限制内容宽度。窄窗口继续使用紧凑版式，可横向滚动的筛选项也加了提示。

**界面的尺寸和动效统一了。** 字号、间距、圆角、阴影和动画时长改用同一套设计 token，减少各个页面之间的差异，也修整了列表行、选项按钮和登录信息的排版。

测试侧：端到端检查共用 MCP 客户端，直接驱动真实应用，并保存失败时的现场与截图对比结果。桌面开发和截图检查默认在独立的无头显示里运行，声音送进虚拟声卡，验证过程不会抢桌面焦点，也不会从真实声卡出声。

构建侧：Rust 工具链统一固定到 1.99.1，开发环境补齐 nextest 和 LLVM 工具；UI 集成测试合并成一个测试产物，开发和测试构建减少调试符号体积。

本版发布桌面 Linux x86_64 产物、Android arm64 APK 和服务端 arm64 镜像（服务端无改动）。安装与部署流程见 [release/README.md](https://github.com/yebei199/osmosis/blob/v0.2.7/release/README.md)。
