# v0.2.5

**遥控模式下电台能续歌了。** 在组里开电台、用另一台设备遥控时，只要在电台列表里点过一首歌，电台就再也不会续新歌。现在点歌之后，电台会接着管这份队列，放到最后一首时照常续歌；在电台以外的地方点歌，电台照旧停下。见 [#182](https://github.com/yebei199/osmosis/issues/182)。

**电台歌单各端一致。** 私人 FM 的歌单改成每个账号一份，存在服务端，手机和电脑看到的完全一样。电台区新增「加载新歌」按钮，按一下就拉一批新歌，所有在线设备同时刷新。听完的歌从列表里移走，切到「已听过」能找回来。心动模式仍由各设备各自拉取。见 [#186](https://github.com/yebei199/osmosis/issues/186)。

**服务端存歌规则改了。** 只有红心的歌永久保留；其余歌曲（包括歌单和日推里的）一天内没听过，每天清理时就会从服务端存储里删掉，下次再放时重新从网易云获取，起播会稍慢。预取也相应收窄：只预取红心的歌和电台新歌，不再在启动时把所有歌单下载一遍。本机手动下载的歌不受影响。

**服务端要先更新**（本版带一次数据库迁移）。旧客户端连新服务端，原来的电台照常能用，只是看不到共享歌单和新按钮。

测试侧改动（验收脚本按编号挑子集）不影响用户，见 [#187](https://github.com/yebei199/osmosis/issues/187)。

本版发布桌面 Linux x86_64 产物、Android arm64 APK 和服务端 arm64 镜像。安装与部署流程见 [release/README.md](https://github.com/yebei199/osmosis/blob/v0.2.5/release/README.md)。
