# v0.2.2

遥控模式下,控制条上的随机和循环开关会显示组里的真实状态,按下去能看到变化,出声的那台也一样。在本机开着电台,再把声音切到另一台设备、自己变成遥控之后,电台会接着往组队列里续歌。续歌仍由开电台的那台设备负责,它下线或被系统挂起时会停。见 [#176](https://github.com/yebei199/osmosis/issues/176)。

顶部的出错提示、播放组条和下载进度条不再浮在页面上挡住内容:它们出现时,页面整体往下让,歌单等控件都点得到。播放页和登录页的背景照旧铺满全屏,只有内容避让。组条上「加入/退出」键的触控高度提到 44px,歌词页的译文开关挪进了标题行。打开播放页再关掉,音乐页的搜索词、筛选和滚动位置都保留。见 [#177](https://github.com/yebei199/osmosis/issues/177)。

桌面端可以下载了,歌存到 XDG 音乐目录下的 `osmosis` 文件夹(通常是 `~/Music/osmosis/`)。同名文件不覆盖,自动加 ` (1)` 一类的后缀。下载中途失败或关窗留下的半截文件,下次启动时清掉。试听片段的提示可以被读屏读出来。见 [#169](https://github.com/yebei199/osmosis/issues/169)。

音乐页新增「已下载」分区,桌面和安卓都有。可以按歌名、歌手或文件名搜索,多选删除,并显示总共占了多少空间。删除前会让你确认一次,删完报告实际删了几首、释放了多少空间。安卓第一次进这个分区时会请求「读取音乐和音频」权限。不给权限也能管理本次安装之后下载的歌;给了之后,重装之前下载的歌也能看到,删除这些旧文件时系统会再确认一次。见 [#178](https://github.com/yebei199/osmosis/issues/178)。

本版发布桌面 Linux x86_64 产物、Android arm64 APK 和服务端 arm64 镜像。本版改动全部在客户端,服务端不需要配套更新。安装与部署流程见 [release/README.md](https://github.com/yebei199/osmosis/blob/v0.2.2/release/README.md)。
