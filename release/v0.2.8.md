# v0.2.8

**输出设备卡住时，播放器不再跟着卡住。** 播放器每秒查一次声音从哪条路由出去（扬声器、蓝牙、有线）。以前这次查询在界面的定时回调里同步等 `wpctl`，蓝牙耳机出错时 `wpctl` 几分钟不返回，进度、自动续播和系统媒体状态就一起停住，界面一直显示「正在播放」。现在查询放到后台，同一时刻最多一个；每条命令最多等 1.5 秒，超时就结束并回收进程。查不出来时按「路由未知」显示，界面不再等这次查询。

蓝牙通道为什么报错还没查清，这一版只是让播放器不被它拖住。按发布时的要求，这一版没有跑测试。

本版发布桌面 Linux x86_64 产物、Android arm64 APK 和服务端 arm64 镜像（服务端无改动）。安装与部署流程见 [release/README.md](https://github.com/yebei199/osmosis/blob/v0.2.8/release/README.md)。
