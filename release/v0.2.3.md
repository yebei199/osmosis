# v0.2.3

在组里开私人 FM，再打开「列表循环」，放到这一批最后一首时，电台会接着续歌，不会再回到第一首把同一批反复播放。关掉循环、开着随机、单曲循环时也一样。没在放电台时，列表循环照旧回到第一首。见 [#182](https://github.com/yebei199/osmosis/issues/182)。

**服务端要先更新。** 这个修复靠服务端告诉客户端「这一首已经是最后一首」。服务端没更新之前，新客户端在列表循环下仍然不会续歌。旧客户端连新服务端，不会出错。

依赖升到兼容范围内最新的正式版。Slint 换到 1.18.1（自维护分支，本地补丁从三条减到两条），Python 测试依赖也一并升级。没有改用户可见的行为。见 [#179](https://github.com/yebei199/osmosis/issues/179)。

本版发布桌面 Linux x86_64 产物、Android arm64 APK 和服务端 arm64 镜像。安装与部署流程见 [release/README.md](https://github.com/yebei199/osmosis/blob/v0.2.3/release/README.md)。
