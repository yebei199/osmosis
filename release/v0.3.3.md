# v0.3.3

播放页换了默认效果：「封面实物」—— 封面是一块有厚度、有光泽的板，立在深色地面上，带倒影；
平时缓慢倾斜，可以拖着转，换歌时翻走再落位。原来的方块点云保留，播放页右上角可以切换，选择会记住。
白色方块和它的标注卡删掉了；宽屏右边那条没有 3D 画面的空带修好了。

喜欢程度变成一条「喜爱度」轴：抽屉里多了「特别喜欢」，分数 = 你选的档（踩 / 赞 / 特别喜欢）
加上按听歌行为算的小幅修正。「我的喜欢」和本地歌单可以按加入时间、喜爱度、播放次数排序，
赞踩筛选换成「特别喜欢 / 喜欢 / 一般 / 不喜欢」四档；心动模式优先拿最喜欢的歌当种子。

服务端先部署，再换客户端：旧服务端不认新的筛选与排序参数。
有数据库迁移（0030，放宽赞踩取值），服务端启动时自动执行。安装与部署流程见 [release/README.md](https://github.com/yebei199/osmosis/blob/v0.3.3/release/README.md)。
