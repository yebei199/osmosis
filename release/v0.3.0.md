# v0.3.0

**界面重做。** 中文改用比例字体 Osmosis Sans（思源黑体 + Figtree），不再是等宽字体那种一个字一个格。每页有标题和一行概况；列表行不再套框，正在放的那首用绿色标题和封面上的跳动条标出。图标统一成 Phosphor 一套。按钮分主次，搜索框换成自己画的。播放条是浮在底部的胶囊，播放键是放大了封面的玻璃透镜；宽屏播放页在点云旁边直接显示歌词。设置里的日月开关换成 unicat 小院：点一下太阳落山、窗户亮灯、猫走回门口。

**「听过」改成真的听过。** 一首歌听过一半或满 4 分钟，切走或放完时才算听过、挪进「已听过」，永久有效。以前一出声就算，正在放的那首会立刻从日推消失。一起听时也会更新。

**打开就知道在听哪首。** 日推按「今天 / 昨天 / 日期」分段；打开时滚到正在放的那首。重启后恢复上次的队列、曲目和进度（暂停状态，不自动出声）。刷新日推不再清掉选中的筛选。

**播放更稳。** 自动下一首跳过在任何设备上听过的歌（列表循环和单曲循环时不跳）。最后一首按下一首，声音真的会停。点开「电台」不再打断正在放的歌。上一首在单人和一起听时规则一致：放过 3 秒按上一首是从头重放，两个方向都跳过屏蔽的歌。

**屏蔽只隐藏。** 屏蔽歌手不再取消你的红心，解除屏蔽后红心原样回来。之前版本屏蔽时已经删掉的红心找不回来。

设置项「动态极光按钮」改为「动态效果」，关掉后弹簧不回弹、透镜静止。

本版要先部署服务端镜像（新增 5 个数据库迁移），再更新客户端。本版发布桌面 Linux x86_64 产物、Android arm64 APK 和服务端 arm64 镜像。安装与部署流程见 [release/README.md](https://github.com/yebei199/osmosis/blob/v0.3.0/release/README.md)。
