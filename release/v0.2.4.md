# v0.2.4

「不喜欢」和「屏蔽」合成一个入口，点下去选一个理由：「不想再听这个歌手」「不想再听这首歌（含其他版本）」「太难听了」。选完后当前这首立即切到下一首，这首歌也马上从列表、队列和组内播放里消失，以后不再出现。同名、同歌手的其他版本算作同一首。屏蔽规则可以在设置里查看和撤回。见 [#181](https://github.com/yebei199/osmosis/issues/181)。

**服务端要先更新**（本版带一次数据库迁移）。服务端没更新之前，新客户端设置不了按歌曲屏蔽的规则。旧客户端连新服务端，按歌曲屏蔽的规则在旧客户端上看不到，也撤不回，其余功能照常。

测试侧的改动（证据目录自动清理、按改动挑选验收场景、每晚全量入口）不影响用户。见 [#183](https://github.com/yebei199/osmosis/issues/183)、[#184](https://github.com/yebei199/osmosis/issues/184)、[#185](https://github.com/yebei199/osmosis/issues/185)。

本版发布桌面 Linux x86_64 产物、Android arm64 APK 和服务端 arm64 镜像。安装与部署流程见 [release/README.md](https://github.com/yebei199/osmosis/blob/v0.2.4/release/README.md)。
