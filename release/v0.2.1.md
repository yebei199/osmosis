# v0.2.1

修复播放组引用失效后遥控操作被「没有这个东西」错误阻断的问题。切换输出设备和其他组操作恢复可用，组引用的队列及精确版本受到回收保护。已有失效播放引用会被清理，设备成员关系保留；选择另一台设备作为输出时，可接续本机当前有效电台曲目与进度。本机没有有效播放时，空组保持空闲。已被回收的旧播放内容无法还原。见 [#174](https://github.com/yebei199/osmosis/issues/174)。

离开遥控组后，本机保留的曲目会显示可点击的播放入口；离组仍停止本机播放，点击后按原规则重播。修复本机重播和切到下一首时缺少播放检查点上报的问题。新增遥控行为验收测试，从真实界面操作贯通鉴权服务、数据库及广播、目标播放器解码到实际采集的音频，覆盖旧功能回归并接入 CI。见 [#175](https://github.com/yebei199/osmosis/issues/175)。

曲目列表的无障碍默认动作与触摸点击共用处理逻辑，读屏和 MCP 可以触发播放及分组展开。见 [#168](https://github.com/yebei199/osmosis/issues/168)。

桌面端暂不支持下载时，提示明确写为「桌面端还不支持下载」。

本版发布桌面 Linux x86_64 产物、Android arm64 APK 和服务端 arm64 镜像。电台修复需要服务端与客户端配套更新；发布资产与实际部署、设备安装分别核验。安装与部署流程见 [release/README.md](https://github.com/yebei199/osmosis/blob/v0.2.1/release/README.md)。
