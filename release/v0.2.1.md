# v0.2.1

修复电台播放切换输出设备时提示「没能改输出设备：没有这个东西」的问题。播放组引用的队列和版本会受到回收保护；已有失效引用会被清理并保留设备成员关系。选择另一台设备作为输出时，可以接续本机当前有效电台曲目与进度。本机没有有效播放时，恢复后的空组保持空闲。已被回收的旧播放内容无法还原。见 [#174](https://github.com/yebei199/osmosis/issues/174)。

曲目列表的无障碍默认动作与触摸点击共用处理逻辑，读屏和 MCP 可以触发播放及分组展开。见 [#168](https://github.com/yebei199/osmosis/issues/168)。

桌面端暂不支持下载时，提示明确写为「桌面端还不支持下载」。

本版发布桌面 Linux x86_64 产物、Android arm64 APK 和服务端 arm64 镜像。电台修复需要服务端与客户端配套更新；发布资产与实际部署、设备安装分别核验。安装与部署流程见 [release/README.md](https://github.com/yebei199/osmosis/blob/v0.2.1/release/README.md)。
