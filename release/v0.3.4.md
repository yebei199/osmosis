# v0.3.4

修好「点了歌不出声、也没有播放条」：从 11 月初起，网易云拒绝了几乎所有取播放地址的请求
（「检测到您的网络环境存在风险」），只有提前存进对象存储的歌还能放。原因是音源服务
bang-dream 发出的客户端身份前后矛盾，那边已经修复上线，不需要客户端更新。
客户端这边：点播失败现在会弹通知说明原因，不再像界面卡住；下一首取不到地址时也不再每秒重试。

播放页的「静止」时间可以设置了：10 秒、30 秒（默认）、1 分钟，或者「播放时一直动」
—— 播放时封面跟着节拍动，暂停才静止。封面实物随低音轻轻一跳；点云铺满整个窗口。

几处修正：组里播放时，新加的屏蔽规则不会再让本机和全组差一首；桌面窗口带上了
`io.github.osmosis` 这个 app_id，任务栏和启动器能认出它。许可证改为 AGPL-3.0-only，
依赖里已知的漏洞已修补。

服务端没有数据库迁移，先换哪边都行。安装与部署流程见 [release/README.md](https://github.com/yebei199/osmosis/blob/v0.3.4/release/README.md)。
