# v0.3.1

手机布局修补，在 1080×2400 竖屏上逐项看过。

- 密码框输长了不再撑出框外：圆点在框里随光标横滚，清除键留在框内。
- 日推筛选条末尾那块深色方块去掉了；筛选 chip 一直排到屏幕边，被边切开就是还能往左划。
- 手机状态栏那一条换成页头的底色，不再是一道黑边。
- 播放页（手机）上沿和下半截压暗，「正在播放」、歌名和歌词压在亮粒子上也读得动。
- 播放抽屉的电台磁贴改叫「开电台」，五块并排不再被截断。

只改客户端界面，服务端镜像照常随版发布，无数据库迁移。安装与部署流程见 [release/README.md](https://github.com/yebei199/osmosis/blob/v0.3.1/release/README.md)。
