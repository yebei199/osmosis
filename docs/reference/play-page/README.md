# 播放页阶段性参考图(临时)

本目录是播放页施工期(issue #7/#11 及后续)的视觉参考,**阶段性资产,做完即删**。
三张图都是外部软件的截图,只作内部对照,不进任何发布产物、不外传。

- `mineradio-particles.png`:Mineradio 的播放页。当前阶段的密度基准:彩纸屑式
  粒子铺满整个视野、大小不一,waveform 环是花瓣状的尖刺轮廓。
- `pointcloud-ref-1.png` / `pointcloud-ref-2.png`:bilibili 上某音乐播放器的
  点云视觉 —— 上万个微点组成随音乐流动的 3D 曲面。这是比彩纸屑更远的一档形态,
  真要做需要 GPU 侧粒子(compute 或 instancing),与
  `docs/note/animated-background-and-compute.md` 的 scatter 判据相关,列为
  候选方向,未排期。
