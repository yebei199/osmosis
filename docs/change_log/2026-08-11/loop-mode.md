# 循环模式(#46)

队列长出循环三态:关 / 列表循环 / 单曲循环,取值与 MPRIS 的 `LoopStatus`
及安卓的 `REPEAT_MODE` 一一对应,上报无损。

## 语义

- 关着时维持原语义:一轮内不重复,放完即停。
- 列表循环在队尾回卷再来一轮;随机也开着的话每轮回卷时**重洗整批**,
  「随机」不退化成固定的循环序。
- 单曲循环只管播完时的自动推进(留在本曲重放);手动「下一首」照样前进。
- 循环跟人不跟批:换一批保留循环模式,随机则照旧清掉。
- 预取(`peek_next`)镜像自动推进的判据;列表循环+随机在队尾预取不到 ——
  下一轮的次序回卷时才洗出来。

## 结构

真相在 `app_core::Queue`(`LoopMode` 字段,`next`/`advance_auto` 两个入口
分手动与自动)。界面上控制簇加第五颗键,单键轮转三态,标签念给读屏;
slint 侧以 int 镜像三态(builtin 之外的枚举过不了访问器)。seam 上
`NowPlaying` 带 `loop_mode`、`MediaCommand` 加 `SetLoop`(绝对值,与现值的
比对在 `wants_loop`);MPRIS 读写 `LoopStatus`,安卓通知加循环键,按一下送
下一态的绝对值。

## Known Cuts

- 安卓通知的循环键三态共用一个 repeat 字形,靠文案分辨;单曲态不另画「1」。
- `previous` 在队首不回卷,维持原状。
