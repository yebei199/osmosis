# 歌词页一轮:歌词页 · CRT 移除 · 进度滑条

2026-08-13 grilling 定案。三件事各自独立提交,对应 TODO 条目做完时删本文件。

## 已定决策

| 问题 | 决定 |
|---|---|
| CRT 范围 | 去扫描线与噪点,vignette 留(它是拢注意力的手段,与复古质感无关) |
| 歌词页入口 | 点播放页歌词区域进入,横滑展开;点非歌词区或返回键退出 |
| 景深实现 | 透明度与字号按行距递减,纯 .slint 属性(Slint 没有高斯模糊,文字无法真模糊) |
| 逐字歌词 | 从设计撤掉,不进 TODO。`LyricLineDto` 只有行级时刻;平台侧有字级数据再评估 |
| 点行跳播 | 不做。歌词可上下拖动浏览,不影响播放进度;点某行仅滚动视图 |
| 进度滑条 | 播放页右侧竖向滑条,时间读数从控制栏迁过去,环形键的比例显示保留 |

## 1. CRT 移除

- `app.slint` 沉浸层删扫描线与噪点两个 Image(§8 注释起约 1559 行),vignette 保留。
- 删 `crates/ui/img/scanline.png`、`crates/ui/img/grain.png`。
- `docs/design/handoff-shaders.md` §8 加一行结案说明:2026-08-13 定为去除,复古质感与
  产品方向不合。

## 2. 右侧竖向进度滑条

- 播放页右侧加竖向滑条:绑 `progress-ratio`,拖动调 `root.seek(float)`
  (`app.slint:101` 回调已存在)。
- 时间读数从控制栏迁到滑条旁,控制栏内那行删除;环形键的比例显示不动。
- 贴边几何真机复核:safe-area inset 桌面恒 0,窗口比手机扁,桌面看不出这类 bug。

## 3. 歌词页

数据(`crates/ui/src/music.rs`、`crates/app-core`):

- `LyricFeed` 现在只吐当前行,加窗口接口:当前行号 + 前后各 3 行(含译文),
  `generation` 判脏沿用 `current()` 那套。
- 窗口选行逻辑写成纯函数,配单测;`app_core::current_line` 继续负责「第几行」。

布局(新文件 `crates/ui/slint/lyrics.slint`,`app.slint` 已过大不再往里塞):

- 当前行满亮满大;每远一行透明度与字号递减,上下各 3 行。
- 译文行跟在原文行下;翻译开关只在任一行有译文数据时显示。
- 可上下拖动浏览;交互停止约 3s 回弹到跟随当前行。

转场与点云:

- 从播放页横向滑出;打开时点云退成背景光(viz 图层不透明度降低),
  世界空间标注卡隐藏。
- 渲染门沿用播放页那套:「展开 ∧ 播放 ∧ 聚焦」。

文档(与实现同批):

- `docs/design.md` 删逐字开关的描述;页面清单「歌词页」落点改为
  `lyrics.slint` + `music.rs`。
