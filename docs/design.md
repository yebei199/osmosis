# UI 设计

界面的设计原则、结构现状,以及改界面前必须过一遍的硬规则。术语的定义在
[`CONTEXT.md`](../CONTEXT.md),每条决策的来龙去脉在 [`adr/`](adr/),这里只讲
它们合起来构成的那个设计。

当前设计来自 2026-11 的整体改版(#56/#67 那一轮之后的第二次):一个字族、Phosphor 图标、
带色相的中性色、`base` 面板压在 `window` 底上、唯一的玻璃材质只给三处。token 的取值与
各组件的规格以 `crates/ui/slint/theme.slint` 与 `widgets.slint` 为真相,本文件只讲合起来
的那个设计和硬规则。2026-08 那一轮的交付稿([`design/handoff-readme.md`](design/handoff-readme.md)、
[`design/handoff-shaders.md`](design/handoff-shaders.md)、[`design/aurora-button.js`](design/aurora-button.js))
冻结留档,其中光带按钮、warp 彩虹环、全屏极光与玻璃卡片都已退役;与本文件冲突时以本文件为准。

## 原则

**功能与氛围分家。** 操作类功能(播/暂/切/进度)由常驻控制条承载;播放页只管
沉浸与氛围,不新增任何只能在它里面完成的操作([`adr/0010`](adr/0010-play-page-decoration-in-3d-function-in-2d.md))。
装饰层可以遮挡界面元素,但被遮挡的东西必须在别处有等价路径;装饰整层消失时,
应用功能完好无损。

**屏幕说什么,耳朵就听什么。** 点歌先换界面:旧歌立刻停,新歌名与封面立刻上,
播放页挂加载态,声音几秒后进来(见 CONTEXT「队列」)。换歌时封面、歌词、播放页场景
都不留上一首的内容等新内容:旧图配新歌比空着更误导。

**出问题的状态自己开口。** 断流停在原地并给一条跨页横幅,文案先说发生了什么,
探明之后再说是哪一种([`adr/0013`](adr/0013-a-broken-stream-is-a-reportable-ending.md))。
静默失败等于把排查成本转嫁给用户。

**界面上没有摆设。** 导航只放真实存在的目的地,开关只在背后有数据时出现,
统计只画真数字。视觉可以先于功能落地,谎报状态的控件不可以。

## 导航

Osmosis 是带 3D 视觉的音乐播放器,导航只有一层:十个平级的目的地(见 CONTEXT
「目的地」,[`adr/0036`](adr/0036-one-level-of-music-destinations.md))。启动落在每日推荐。

- **宽版式导航**(≥ 600px):左侧 224px 侧栏,顶上品牌行,下面一行一个目的地(图标加全名,
  行高随窗口高度在 32–40px 之间取)。从上到下每日推荐、电台、搜索 | 我喜欢、我的歌单、
  最近播放、已下载 | 沉底个人、设置。分组之间只留间隔,没有父级页面。内容区是一块
  `base` 面板,离窗口边 8px、圆角 20,压在 `window` 底上 —— 分隔靠面板,不靠描边。
- **紧凑版式导航**(< 600px):底部 64px(加手势条 inset)五格等分 ——
  推荐 / 搜索 / 我喜欢 / 歌单 / 更多。格上显示简称,无障碍标签报全名(「每日推荐」
  「我的歌单」)。「更多」点开贴在底栏上沿的平铺面板,一行五项:电台、最近播放、
  已下载、个人、设置;点一项直达并收起,点面板外也收起。当前页在面板里时「更多」
  保持选中,音乐页的页头写真实目的地的全名。控制条浮在底栏之上。
- **控制条跨目的地常驻**:窗口级一个实例,悬浮在底部,有歌就在。没有缩小形态 ——
  「迷你条」曾是三处不一致的最大来源([`adr/0029`](adr/0029-player-bar-is-main-bar-plus-drawer.md))。
- 播放页不占导航位,从控制条的封面展开、再点封面收起(见 CONTEXT「播放页」)。

## 音乐页:卡墙与列表

音乐页主视图是 3D 卡墙:当前一批曲目的封面卡在深度上散开,拖动旋转、滚轮推拉、
单击浮起、双击播放。列表与卡墙是同一批卡的两种摆法,切换只是深度插值,不换页面
([`adr/0025`](adr/0025-card-wall-is-the-music-main-view.md))。
无 GPU 的构建(web / iOS 默认)退回列表视图。

音乐页没有自己的导航:每日推荐到已下载这七个目的地共用它,换目的地就是换这一页
摆的那一批(见上文「导航」)。页头右侧是「卡墙 / 列表」分段与「播放」主按钮;列表上方
一排筛选芯片(分组是带下拉的选择芯片,「已听过」是开关芯片)。「我喜欢」与本地歌单在
这一排最前面多一颗「排序」选择芯片:加入时间 / 喜爱度 / 播放次数,次序由服务端排。

卡墙的列距行距按容器尺寸计算,不写死像素:原稿里两处卡墙用了两套坐标,
跨尺寸复用会错位。

## 版式

两种版式,由视口宽度决定,与端正交:< 600px 逻辑像素为紧凑版式,否则宽版式
([`adr/0007`](adr/0007-layout-mode-by-width-not-by-platform.md))。桌面把窗口
拖窄就能看到移动端的样子,移动端排布因此在桌面上可见、可验证(`just shot 420`)。

紧凑版式的要点:卡墙降到 2 列且相机后撤(`render3d` 的 `pullback`);控制条
只留封面 / 文字 / 上一首 / 透镜 / 下一首 / 抽屉键;个人主页统计卡 2×2;设置页分组导航折叠成整块卡片流;
触摸目标不低于 44px。播放页那张 220px 封面卡已随封面点云上线删除,3D 场景自己铺满整屏。

## 主题与色板

明暗两套主题,外加「跟随系统」:设置页的日夜开关拨显式明 / 暗,「跟随系统」单列一项,
存储是三值枚举(`api::settings`),真相在 Rust 侧(`crates/ui/src/theme.rs`)。跟随系统的
检测当前只有桌面端实现,其余端按深色处理。

颜色全部收在 `theme.slint` 的语义 token 里,具体值以该文件为真相。中性色带强调色的色相,
深色下表面一档约 4.5 L*(window → base → surface → raised)。三族表面不混:

- **常驻界面**(window/base/surface/raised/sunken,叠加层 hover/press/line/edge):
  导航、面板、列表、控制条、卡片,跟着明暗走。
- **沉浸层**(immersive\*):播放页压在糊封面与点云上的那块底和字,两套主题下
  取值相同。底钉死,字就得跟着钉死(`crates/ui/tests/theme.rs` 守着)。
- **错误**(danger\*):只用于提示里的错误图标,不当强调色用。

**绿是唯一的强调色**([`adr/0023`](adr/0023-green-is-the-only-accent.md),取值由
[`adr/0039`](adr/0039-accent-text-follows-the-accents-lightness.md) 修订)。`accent` 用于实底
(主按钮、开关、进度、均衡条),`accent-text` 是压在实底上的字,`accent-ink` 是中性底上
表示「这很重要」的字与图标(正在播放的歌名、当前导航、红心)。红心不再有自己的粉色。

**副色板 12 对**只用于封面占位、卡墙卡片、统计数字:一屏里颜色可以很多,「重点」
永远只有绿。真实封面到位后,它们只作为加载前的占位与失败兜底。

**阴影三档**(`Elevation`):`card`(面板、设置卡片)、`float`(控制条)、`overlay`
(抽屉、提示)。一个矩形最多一道外阴影、一道内阴影、一条边;软件渲染器不画阴影,
无头截图上它们不可见。

## 字体与图标

一个字族 **Osmosis Sans**:Figtree(拉丁与数字,`tnum` 在构建期冻进字形,时长与进度
自然对齐)合并 Noto Sans CJK SC 的 GB2312 / JIS X 0208 / Big5 一级 / KS X 1001 子集,
三个字重 400 / 600 / 700。安卓只带拉丁那半,中文由系统的 Noto Sans CJK 接,是同一个设计。
构建与覆盖检查在 `just font-subset`。字号阶梯在 `TextSize`,页面标题一律 `display`
(紧凑 `display-compact`),播放页歌名 `hero`。

图标是 **Phosphor 2.1**(`crates/ui/icons/`,`icons.slint` 的 `Icons`):一律 Regular,
Fill 只表达状态(当前目的地、已红心、播放 / 暂停 / 切歌、警告)。不用 Unicode 字形当图标。

## 玻璃与透镜

玻璃是唯一的签名材质,只许出现在三处:播放键、正在播放那一行的缩略图、导航指示器。
其余一律不透明。

**播放键是封面透镜**([`adr/0038`](adr/0038-the-play-key-is-a-cover-lens-not-a-shader.md)):
圆形裁剪里画当前封面放大 190%、上移 8%,压一层暗幕,左上一块椭圆高光;外圈一道
conic 进度环。按下缩到 0.92(`Motion.press`),悬停时朝指针偏 ≤ 4px(`Motion.lean`)。
全是 Slint 图元,不加 shader;进度靠属性重画,不要帧。正在播放那一行的缩略图是同一个
透镜的小号,叠三根均衡条(暂停时落到 3px)。

**导航指示器**宽版式是侧栏行后面那块玻璃,底栏是图标后面的小药丸;两条边各用一条弹簧
(`Motion.lead` / `Motion.trail`),往下走时先拉长再回弹。有 GPU 的端由 `navglass` pass
画,没有的端退回 Slint 的 `GlassPill`。

**动效**:弹簧用贝塞尔近似(`Motion.*`),设置「动态效果」关掉时全部换成 200ms ease-out
(`Motion.calm`),日夜开关的弹簧也一起收。空闲时一帧不出(下文硬规则 7)。

## 水滴导航

选中指示器由三颗球组成(头球/尾球/小水滴),追随系数 0.30/0.19/0.13,同一个
目标位置因系数不同天然拉开先后;Slint 侧粘合用 SDF smooth-min(k≈14px),
不用滤镜链。拆解在 [`design/handoff-shaders.md`](design/handoff-shaders.md) §11,
落在 `render3d` 的 `navglass` pass。宽版式侧栏沿 y 走,手机底栏沿 x 走:同一套
数学,轴对调,系数与三球比例共用(#70)。

轨道的范围两种版式不同:底栏五格(含「更多」)全在轨道上,「更多」面板里的目的地
都落在第五格;侧栏轨道是上面两组七行,分组间隔计进位置(`nav-target-y`)。沉底的
个人与设置不在轨道上、自己画选中底(#71 的规则沿用):选中它们时水滴停在轨道最后
一行(已下载)上并化掉,不然上面还亮着一格、人却在别的页。

## 播放条

**只有一种形态**([`adr/0029`](adr/0029-player-bar-is-main-bar-plus-drawer.md)):
条身是 `raised` 上的悬浮胶囊(72px 高,紧凑 64px;宽不超过 760px,所有页面同一套尺寸,
`BarMetrics` 是唯一的一份)。主条只放高频核心:圆形封面 · 曲名 / 歌手 + 时间 · 上一首 ·
透镜 · 下一首 · 红心(仅宽版式)· 抽屉键。封面兼任播放页的进出口。窄容器里让位的是
文字列,按键与透镜永不缩。条身下缘一道 3px 细轨管精确拖动,把手在悬停 / 拖动时出现。

其余功能住进**向上展开的抽屉**(同宽,`overlay` 阴影,圆角 28):一排六格动作
(已喜欢 / 点赞 / 特别喜欢 / 不喜欢 / 下载 / 从这首开电台,[`adr/0042`](adr/0042-affinity-is-one-bounded-axis-anchored-by-what-you-said.md)),下面是带字的行 —— 随机(开关 + 白话状态)、
循环(关 / 列表 / 单曲分段)、音量(滑杆 + 数字)、输出(设备芯片)。到处同一层,行数与
高度不随页面变。点条外任意处收起。

## 播放页与可视化

播放页的装饰在 3D、功能在 2D([`adr/0010`](adr/0010-play-page-decoration-in-3d-function-in-2d.md))。
最底层是这首歌封面的糊图(CPU 上每首歌算一次),上面是一层铺满整窗的 3D 场景,画的是
用户选的**效果**(见 CONTEXT「播放页效果」,[`adr/0041`](adr/0041-the-cover-as-an-object-is-the-default-effect.md)):
默认是**封面实物** —— 封面印在一块带倒角的薄封套上,立在暗色亮面地板上,下面是淡出的
倒影与接触阴影;另一个是封面点云。右上角一枚药丸写着当前效果,点开是一列带字的行,
当前那行强调绿加勾;选择跟着设备记住。
功能层就是那根全应用共用的控制条 —— 同宽、同高、同一层抽屉,封面翻成「收起」。
歌名用 `hero` 字号,歌词与歌名同层画在场景之上,不参与深度合成。宽版式主体在左,
右边一列是歌名、歌手、队列入口和内嵌的几行歌词;紧凑版式主体在上,歌词只露一行。
「在左 / 在上」由 3D 相机移轴做,场景图本身铺满整窗,哪一边都不会空着一条。

封面实物跟着音乐的是事件,不是电平:每一下底鼓往前顶 2.5%、点头约 1.3°,200ms 内收回且
不往后缩;响的段落呼吸摆幅放大到最多 2.2 倍;镲片只让光泽闪一下;低频电平推亮倒角边缘光。
不逐帧跟着电平抖 —— 一张实物封套持续地抖看着像坏了。它自己的运动另有很慢的呼吸(±3°)、
拖动后回弹、换歌时旧的甩走新的落位(0.8s,其间不起新鼓点)。

封面点云的封面那一块之外,同格距的方块铺满整个视口,取封面边缘外延的糊色,压暗并往窗口边
沉下去 —— 满屏是方块,主体仍是中间那张清楚的封面。

seek 只有一个面:条上那道细轨(曾经的右缘竖向进度条随 `adr/0029` 退场 ——
同一页两套 seek 面,槽宽、颜色、把手规则各一套)。时间读数也只剩条上那一份。

播放页没有参与深度合成的 UI:世界空间标注卡、它标的那枚方块与遮挡层已随
[`adr/0041`](adr/0041-the-cover-as-an-object-is-the-default-effect.md) 删除。

点播放页的歌词,歌词页从右侧横向滑出,场景退成背景光,效果入口让位。
景深由透明度与字号按行距递减做出来:Slint 没有高斯模糊,文字要真模糊就得进
3D 走一套字形管线,而那正是卡墙里砍掉内嵌文字的同一笔账。翻译开关只在有译文
数据时出现。歌词可上下拖动浏览,不碰播放进度,松手三秒回到跟随。

逐字歌词不做:`LyricLineDto` 只有行级时刻,平台侧给出字级数据后再评估。

可视化只在「播放页展开 ∧ 正在播放 ∧ 窗口聚焦」时渲染,任一条件不满足即完全
停止:暂停定格在最后一帧,收起与失焦零重绘。

沉浸层不做复古质感:扫描线与噪点已于 2026-08-13 去除(#74),只留一道
vignette 收边,把注意力拢回中心。

效果切换住在播放页右上角而不在抽屉:选的是这一页自己的样子,只在这一页看得见。它不是
硬规则 4 说的「只能在这里完成的操作」—— 那条管的是音乐功能;效果是装饰的外观,换不换
都不影响播放(`adr/0041`)。

## 硬规则

都是违反过、或原稿里点名会出问题的,改 UI 前过一遍:

1. 新颜色进 `theme.slint` 的 token,不在别的 `.slint` 里写字面色。例外只有
   图形性绘制(unicat 日夜开关的像素,它自己算)与调试读数。
2. 版式由宽度决定,不由端决定。不写「安卓 = 底部导航」式的分支。
3. 可视化不承载功能,被它遮挡的元素必须在别处有等价路径。
4. 播放页不新增只能在这里完成的操作。
5. UI 依赖 app-core 的方向永久单向,反向禁止(见 CONTEXT「UI 层」)。
6. 绿是唯一的强调色。副色板绝不用于按钮、选中态、链接、状态色。
7. 按需渲染,静止不烧 GPU(2026-09-27 推翻「前台恒满帧」,#153,理由与唤醒机制见
   [adr/0035](adr/0035-render-on-demand-with-one-wake-path.md))。渲染循环只在有东西在动
   时要下一帧:交互中、过渡中、环境动效的活跃期内,动起来仍是屏幕刷新率。常驻的环境
   动效(播放页场景、卡墙)连续 10 秒没有用户输入就定格,任何输入立即恢复;定格期间
   状态变了照样画出新的一帧,只是不连续动。播放页之外放着歌也不要帧。看不见的不画。
   不经 Slint 属性就改了画面的到达,一律经 `runtime::pace` 那三个回调叫醒循环,不许
   另开一条路。
8. 界面上不放假东西:假入口、无数据的开关、编造的统计都不上屏。
