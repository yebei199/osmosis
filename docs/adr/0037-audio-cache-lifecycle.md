# 曲目音频的缓存生命周期

日期:2026-11-06。状态:已采纳。修订 #186 的保留期规则。

## 背景

网易云取播放地址时会随机回「网络环境存在风险」,听的时候现取就可能放不了。缓存因此改为提前存,
服务端每三分钟问一次网易云。电台和日推都是推给用户筛选的歌,用同一套规则。

## 决定

一首歌在桶里的去留只看它此刻的状态:

| 状态 | 列表里 | 音频 |
|---|---|---|
| 红心 | 「我喜欢」,电台和日推不再摆 | 永久保留,不算未听池 |
| 未听(在电台或日推里,还没「听过」) | 主列表 | 留到听过,或被未听池上限挤掉 |
| 听过,没红心 | 「已听过」 | 北京时间当天结束后删 |
| 被挤出未听池 | 主列表,歌名还在 | 没有。听到时现取,再排进预取 |
| 屏蔽 | 不出现(红心留着,只是藏起来) | 不下载,已有的删掉 |

- 未听池上限 20 GB,每小时清理时按存入先后从最早的删起。总上限 85 GB 不变,未听池名次排在红心之后。
- 未听的电台加日推少于 500 首时,服务端补一批。后台每 30 分钟检查一次,听歌时也检查。
- 预取先取没听的日推,再取没听的电台歌,最后才是红心。
- 日推累积保留,取当天这批只问平台一次。
- 建屏蔽规则时命中的歌从电台和日推删除,撤掉预取,删掉音频;规则解除后这些不会自己回来。
  **红心不动**(2026-11-10 修订,用户定「屏蔽只是藏起来」):「我喜欢」在出口按规则藏,
  规则解除就原样回来。此前按旧规则被解除的红心找不回来。

「听过」的口径 2026-11-10 收紧:不是出声即算,而是结束时累计听满一半或 240 秒(见
`CONTEXT.md`「听过」)。表里的「未听」「听过」都按它。

## 影响

本决定取代 #186 的「一天没播就删」。没听的歌不再有时限,磁盘占用靠未听池上限约束。
