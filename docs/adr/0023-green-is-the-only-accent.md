# 绿是唯一的强调色,accent-text 反转为深墨

日期:2026-08-11。状态:已采纳。

## 背景

2026-08 整体改版把身份色从琥珀换成绿(深色 `#8fc46a`、浅色 `#4f7a3f`)。
换色本身是 token 值的替换,但牵出两个必须定死的语义问题:强调色到底有几个,
以及压在强调色实底上的字是什么颜色。

改版同时引入了一个 12 对渐变的副色板,用于封面占位、卡墙卡片、波形条、
统计数字。一屏之内颜色数量大增,「哪个颜色表示重点」第一次需要明文回答。

## 决策

- **绿是唯一的强调色。** 按钮、选中态、链接、状态高亮只用 `accent` 一族。
  副色板不承担任何界面语义:它可以让一屏很花,但用户看到绿就知道那是重点。
  这条进 `docs/design.md` 硬规则。
- **`accent-text` 从近白反转为深墨**(深色 `#0f2410`)。琥珀年代它是
  `#f0e6d8`,压在琥珀实底上约 4.6:1;绿的明度高得多,近白字压上去只有约
  1.9:1,深墨约 9.4:1。`crates/ui/tests/theme.rs` 的对比度断言随之更新,
  这个反转是测试期望的变化,单看 diff 会以为写反了,故记档。
- `accent-ink`(中性底上表示选中的字与图标)不受影响,仍随主题翻转。
  它与 `accent-text` 分开的理由不变:两者压的底一个随主题翻、一个不翻。

## 备选方案

**多强调色:副色板同时承担语义**(比如每个页面一个主色)。不选:12 对颜色
轮转时「重点」失去稳定身份,选中态在不同页面长得不一样,用户要重新学。

**保住近白 accent-text,把绿压深到能托近白字**。不选:够深的绿(约
`#3a6b28` 以下)在深色底上失去亮度对比,按钮读不出「亮起」的观感,等于
为了字牺牲了键。

## 代价

- 主题 token 的取值全部换过,依赖旧琥珀观感的截图基线作废,`just shot`
  重截。
- 副色板 12 对进 `theme.slint`,token 数量近乎翻倍;硬规则第 6 条是防止
  它们被误用的唯一防线,review 时要盯。
