# 封面实物是播放页的默认效果,标注卡与遮挡层退役

日期:2026-11-12。状态:已采纳。取代 [`0014`](0014-one-visual-preset-with-the-seam-left-in-place.md);
修订 [`0010`](0010-play-page-decoration-in-3d-function-in-2d.md) 的「粒子从卡片前后穿过」与
「深度卡片现在是标注卡」两节、[`0012`](0012-cover-point-cloud-is-one-mesh-in-the-bevy-scene.md)
的「自动同时进两台相机、白拿遮挡设施」。

## 背景

播放页的 3D 主体是封面点云:九千多颗方块砌成的封面随声音起伏。用户判它当默认不好看 ——
那是一层「效果」,不是这首歌的封面本身。

同一页上还有三样只为一个演示存在的东西:一枚绕轨道慢转的白色方块、挂在它前表面上的
世界空间标注卡、以及为了让粒子逐像素挡住那张卡而开的第二台相机(遮挡层)。卡片的内容是
曲名,下方的歌名行就写着同一句话;遮挡层每帧把整个场景再提交一遍(真机量过 +22%)。
它们证明了「深度正确的 UI」做得出来,但在播放页上没有产品意义。

另有一处版式缺陷:宽版式为了给右边那栏字腾地方,`.slint` 把整张场景图往左推了两成窗宽,
而图本身只有一个窗宽 —— 右边那 20% 没有任何 3D 内容,出界的东西在那条边上被硬切。

## 决策

**一、默认效果是「封面实物」**(`crates/render3d/src/sleeve*`)。封面印在一块薄封套上
(圆角、半圆倒角、厚度 3.4%),一盏写死在着色器里的柔光从左上照着,正面一道很淡的光泽随
偏转滑过;下面一片暗色亮面地板,地板里是封套淡出的倒影与一道接触阴影。

- 倒影是一份**镜像网格**,不是第二台相机、也不是屏幕空间反射。镜像烘进几何(y 取反、绕序反转),
  实体的变换因此仍是正常旋转,背面剔除照开。地板与倒影半透明:桌面 `Blend`,安卓 `Mask`
  加 4×4 有序抖动 —— Adreno 上 Blend 整片不显示的坑([`0012`](0012-cover-point-cloud-is-one-mesh-in-the-bevy-scene.md)、
  `crates/render3d/README.md`)还在。
- **随音乐动的只有光**:平滑过的低频推亮倒角那一圈边缘光。几何不跟鼓点抖 —— 那是点云的语言,
  一张实物封套跟着节拍晃,看着像坏了。
- 运动只有三种:很慢的呼吸(约 ±3° / ±2°,11s 与 15s 两个周期);拖动偏转(橡皮筋,上限约
  40° / 25°)、松手由欠阻尼弹簧拉回原位;换歌时旧封套加速甩向左后方并翻开,新封套从它后面
  落位、冲过头一点再停,0.8s。两张始终不互相穿过,不靠透明度遮丑。
- 先换歌、封面后到(绝大多数情形):旧封面甩走,落位的是一张空封套,封面到了在上面显影;
  不甩第二次。「不留着上一首」与点云同一条规矩。

**二、「效果」是顶层选择,点云降为可选的第二个。** 编号 seam 从「点云的子预设」改为「效果」:
`Viz.viz-effect`(0 封面实物、1 点云)→ `VizControls::effect` → `VizFrame::effect` →
`render3d::effect::Effect`。两摊实体常驻,只有当前那一摊可见,另一摊 `Visibility::Hidden`,
一帧不画;两摊都收封面,切过去不重建、不等图。点云的 `preset` uniform 与 `preset_index`
一并删除 —— 只剩一档的子预设没有存在的理由(这正是 0014 留着那条 seam 等的「加第二档」,
只是第二档长在了上一层)。

- 入口在播放页右上角:一枚与左上角队列入口对称的药丸写着当前效果名,点开是一列带字的行,
  当前那行强调绿加勾([`0023`](0023-green-is-the-only-accent.md))。0014/0029 说过「加档时回到抽屉里」,
  这里不照做:选的是这一页自己的样子,只在这一页看得见;放进全应用共用的抽屉,在别的页面上
  就是一行点了看不出变化的设置。它也不违反 `docs/design.md` 硬规则 4 —— 那条管的是音乐功能
  (播、停、切、进度),效果是装饰的外观,换不换都不影响任何功能。
- 选择跟着设备落盘:`api::settings` 加 `viz_effect`,写名字(`object` / `cloud`)不写编号,
  认不得的名字只把这一项落回默认,不连带冲掉音量。

**三、删除标注方块、标注卡与遮挡层。** `marker.rs`、`viz-anchor-*`、`viz-occluder`、
`spawn_occluder_camera` / `occluder_depth` / `anchor_viewport`、`VizFrame::needs_occluder`、
`VizImages` 全部删除;`render_viz_frame` 只交回一张场景图。播放页的合成从五层变成三层:
糊封面背景 → 3D 场景 → 字与控制簇。

0010 的边界随之收窄:**「装饰入 3D、粒子可以从卡片前后穿过」那一档退役**。播放页上不再有
参与深度合成的 2D 元素;「装饰在 3D、功能在 2D」与「被遮挡的东西必须在别处有等价路径」两条
照旧有效。深度正确的 UI 这条路线没有被否定 —— 它的做法与代价记在 0010、0012 与
`docs/blog/depth-correct-slint-ui-over-bevy.md`,哪天有一个真正需要被场景挡住的对象,
从 git 里取回来。

**四、主体的「偏左 / 偏上」由相机移轴做,场景图铺满整窗。** `.slint` 不再平移那张图;
`VizFrame::compact` 把版式带进 render3d,`camera::lens` 用 bevy 的 `SubCameraView` 把主轴放在窗宽
0.3(宽版式)或窗高 0.36(紧凑版式)处。移轴与「把居中渲好的图整张平移」逐像素相同,点云的
观感一点不变;区别是平移出去的那一边也有内容。纵向移轴时 bevy 把视野对齐到整幅画面的高,
视野按同一倍数放大才不缩放(单测钉着)。bevy 的视锥剔除仍按不移轴的那一幅算,两个效果的
实体都挂 `NoFrustumCulling`。

## 备选方案

**把点云调好看,不加新效果。** 不选:问题不在参数,在形态 —— 九千个方块是一层「效果」,
用户要的默认是「这首歌的封面」本身。点云留着,给想要它的人选。

**封面实物用 bevy 的 PBR(`StandardMaterial` + 灯 + 阴影 + 屏幕空间反射)。** 不选:要开阴影
贴图、prepass 与一整套光照绑定,地板反射还得另起一台镜像相机或 SSR,安卓上又是一摊没验证过的
管线;这里要的只是「一盏灯照着的纸板」和一道淡倒影,一份几十行的片元着色器加一份镜像网格就够。

**宽版式把主体在世界里往左挪,不移轴。** 不选:点云会被斜着看(离开光轴),观感变了;
封面实物露出一侧的厚度,与右侧那栏字的视线方向不一致。移轴让两者都与从前逐像素一致。

**留着标注卡,换一个更有意义的被标注物。** 不选:播放页上没有需要被场景挡住的信息,
每帧 +22% 的第二遍绘制换不来任何东西。

## 代价

- 两个效果的管线都按「第一次可见」才编译:第一次切到点云时有几帧空白。没做预热 —— 切换是
  低频操作,不值得给它也排一条卡墙那样的预热。
- 封面纹理没有 mip:封套在小屏上缩到三四百像素时,高频的封面细节会有一点闪。要压就得给
  上传的封面生成 mip,那是 `scene/cover.rs` 的事。
- 安卓上的倒影与地板是抖动出来的,近看有网点;远看与桌面的混合一致。
- 编号在 `.slint` 的 `viz-effect-names`、`ui::viz::effect` 与 `render3d::effect` 三处手工对齐。
