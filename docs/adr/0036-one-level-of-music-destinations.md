# 纯音乐播放器:九个一级目的地,一层导航

日期:2026-10-24。状态:已采纳(MEO-1876,导航方案见 MEO-1884)。取代 `0024`;
修订 `0029` 里「首页」「跨应用」那几处表述。

## 背景

`0024` 把 Osmosis 定成承载多个应用的壳:Home 是应用启动器,音乐是第一个应用。
一年下来壳里始终只有音乐一张真瓦片,背单词与资讯、视频源一行代码都没有。壳的代价
却一直在付:导航有两层 —— 外层四个 tab(Home / Music / 个人 / 设置),Music 里面
又是一套六分区的竖栏或分段条;红心没有独立入口,只能从「我的歌单」里点进去;
`docs/design.md` 写的底栏(Home / Music / 搜索 / 我的)和实现对不上。

用户 2026-10-24 定下方向:osmosis 是带 3D 视觉的音乐播放器,去掉 Home 和两层导航,
启动直接进音乐(MEO-1868、MEO-1875)。导航的具体排布在 MEO-1884 拍板。

## 决策

- **九个一级目的地,彼此平级**:每日推荐、电台、搜索、我喜欢、我的歌单、最近播放、
  已下载、个人、设置。它们取代「外层四 tab + 音乐内六分区」,成为一个状态
  `Shell.destination`。编号沿用原音乐分区的 id(0–5),后加的接着排(6 我喜欢、
  7 个人、8 设置);条目表在 `crates/ui/slint/musicnav.slint` 的 `Destinations`。
- **宽版式**(≥ 600px):一条带字的侧栏,从上到下每日推荐、电台、搜索 | 我喜欢、
  我的歌单、最近播放、已下载 | 沉底个人、设置。分组之间只留间隔,没有父级页面。
- **紧凑版式**(< 600px):底栏「推荐 / 搜索 / 我喜欢 / 歌单 / 更多」。「更多」点开
  一块平铺面板,列出电台、最近播放、已下载、个人、设置,点一项直达并收起。当前页在
  面板里时「更多」保持选中,页头写真实目的地的全名。底栏显示简称,无障碍标签报全名。
- **启动落在每日推荐**,卡墙作为它的一种视图照旧。
- **「我喜欢」复用 `Source::Liked` 的数据**,不新增数据模型。
- **删除**:Home 启动器、它的星云空槽、`current-tab`、MusicRail 与 MusicBar、
  侧栏底部那两颗 glass 圆钮。`Shell` 这个 global 不整块删:里面的播放、设备、
  GPU 纹理状态照旧,它现在只是窗口级的状态面,不再代表「壳」这个产品概念。
- **水滴导航沿用**:侧栏沿 y 走七行轨道(沉底两行仍不在轨道上,`#71` 的规则不变),
  底栏沿 x 走五格。

## 备选方案

**紧凑版式九项横滚**。不选:首屏看不全,用户得先知道要滚才找得到设置。

**紧凑版式五项 + 一个聚合页**。不选:聚合页就是换了名字的容器页,两层导航又回来了。

**保留 Home,只把它改成音乐首页**。不选:`0024` 当初否决它的理由(和音乐页抢同一批
内容)仍然成立,而壳这个理由已经不在了。

## 后果

- 「壳」「应用」两个词条从 `CONTEXT.md` 移除;控制条的归属从「壳持有、跨应用常驻」
  改成「窗口持有、跨目的地常驻」,形态不变。
- `0029` 列的「四处实例(首页、个人主页、设置、音乐页、播放页覆层)」里首页不再存在;
  一根条、一种形态的决定本身不变。
- 侧栏从 96px 图标栏变成 168px 带字侧栏,内容区相应窄了 72px。
- 星云(`nebula`)变体在界面上暂时没有用处,着色器里那条分支保留,不在本次范围内清理。
- 调试开关 `OSMOSIS_TAB` 换成 `OSMOSIS_DESTINATION`,编号按目的地算。
