# 网易云取播放地址的风控(2026-11-06 调查)

取播放地址时网易云会回 400「检测到您的网络环境存在风险，请稍后再试」。bang-dream 把它记成内部错误,
服务端回 502,客户端这首放不了。缓存规则因此改成提前存,见 [ADR 0037](../adr/0037-audio-cache-lifecycle.md)。

## 查到的

- 逐请求随机被拒。同一首、同一档位重复请求,一会儿过一会儿不过。
- 与歌、档位、出口 IP 都无关:德国生产和本机结果一样。
- 与会员无关。账号当时黑胶 VIP 有效,到 2026-11-22;没权限时回的是空地址,显示为「无可播放源」。
- bang-dream 只限单账号在飞请求数,没有频率限制。

| 条件 | 被拒 |
|---|---|
| 生产预取,20 次/分 | 36/71 |
| 本机直连,2.5 秒一次 | 13/24 |
| 生产 `/play` 连发 | 6/16 |
| 生产 `/play`,10 秒一次 | 8/16 |
| 生产预取,3 分钟一次,前 24 分钟 | 3/11 |

## 还不知道的

是不是频率造成的没有证实:0.3 秒到 10 秒之间拒绝率没变,3 分钟一次的样本又太小。可能是窗口更长的账号级冷却。

## 怎么接着查

从服务端日志数 `GetPlaySource` 和 `预取失败.*502` 的比值。拒绝率仍高就把 `PREFETCH_NETEASE_INTERVAL_SECS`
调到 240,再不降就去 bang-dream 查请求身份。成功请求 bang-dream 不记日志,要在 osmosis 这边数。

## 0.2.11 上线时没有验证的

- 日推页「已听过」按钮和红心列表按标签筛选,没在真实界面上跑过,只有客户端测试。
- 屏蔽清理和 20 GB 上限线上还没真实触发过,只有测试覆盖。
- SM-A376B 未在线,没有装 0.2.11。
