# Shader / Bevy 效果 · 八个方案的分层拆解

对应设计稿 `Osmosis 播放器改版.dc.html` 的 `#2a` … `#2i`。每个方案在设计稿里都有一张卡：左边是会动的 CSS 近似（只表达观感与节奏），右边是分层拆解。**近似不是实现** —— 参数以本文件为准。

所有效果都必须挂在仓库既有的省电门下：3D 场景走 `render-active`，播放页 warp 走「展开 ∧ 播放 ∧ 可见」，导航选中器走转场门。**没有任何一个效果可以让静止画面每帧重绘。**

---

## 建议顺序（从便宜到贵）

| 顺序 | 方案 | 改动面 | 理由 |
| --- | --- | --- | --- |
| 1 | §8 grain + 扫描线 | 一个全屏后处理 pass | 十几行 WGSL，零架构改动，"略微复古"最便宜的一笔 |
| 2 | §9 动态极光按钮 | 一个小纹理 pass | 独立、可单独开关、失败不影响任何功能 |
| 3 | §4 封面取色喂极光 | 三个 uniform | 不改管线，只多喂数据；顺带解决"副色调丰富"的配色问题 |
| 4 | §1 换歌过渡 | 同一 mesh + 一张纹理 | 换歌是最高频动作，观感回报最大 |
| 5 | §2 音频驱动位移 | 接 `viz.rs` 现有 seam | seam 已经在，目前没有消费方 |
| 6 | §7 状态即视觉 | 两个 uniform | 与 ADR-0013 的断流上报配套 |
| 7 | §6 歌词体积景深 | 新增 CoC 计算 | 要动歌词层的渲染 |
| 8 | §5 玻璃真折射 + metaball / §3 相机推近 | 动 glass pass 与页面切换 | 最重，动到架构 |

## §1 换歌过渡 · 体素塌落重聚（`#2a`）

现状是硬切。

1. 顶点着色器同时持有**上一首**与**下一首**两张封面纹理，位置与颜色按 `t ∈ [0,1]` 做 `mix`。
2. 中段（`t` 约 0.25–0.75）把位置换成 **curl noise 流场**，颜色暂时脱离网格 —— 这是"散开"的观感来源。
3. 回落用 `smoothstep` 错峰：每颗粒子的延迟 = 归一化的到中心距离 × 0.9，中心先落、边缘后落。

总时长 900ms。同一个 mesh、同一个 draw call，只多一张纹理与一个 uniform。

**边界**：换歌比过渡快时（连按下一首）直接把 `t` 重置为 0 并换纹理，不排队。

## §2 音频驱动位移 · 频谱即高度场（`#2b`）

`src/viz.rs` 已经有音频载荷的取帧 helper 和 `VizControls` / `VizFrame` 这条 seam，**目前没有消费方**。接上即可，无新架构。

1. **低频（0–4 bin）** → 整片起伏，慢，做"呼吸"。
2. **中高频** → 只抖顶面 1–3px，做"颗粒"。
3. **位移后必须重算法线** —— 不重算的话高光不跟着动，起伏在画面上读不出来，白算。

wasm 侧数据源恒空，取帧代码无平台判断（`viz.rs` 已经这么写了），此时退化为静止点云，不报错。

---

## §3 列表 → 播放页 · 相机推近（`#2c`）

把"3D 是一个页面"改成"3D 是一条贯穿的深度轴"。

1. 列表行的封面**本来就是** 3D 场景里的一张卡，2D 只画占位（或干脆不画）。
2. 展开 = 相机 dolly + 卡片 `rotateX` 展平，Slint 那层同时淡出。420ms。
3. **落位之后才起点云**，否则相机运动与点云位移两套位移叠在一起，看起来像抖。

竖视口相机要后撤（`render3d` 的 `pullback`），这是 ADR-0007 外溢到渲染层的唯一一处。

---

## §4 封面取色喂极光（`#2d`）

1. 封面缩到 16×16，k-means 取 3 色，**丢掉近灰的**（饱和度低于阈值的直接弃，否则一堆脏灰）。
2. 三色喂 `glass.slint` 那三团光斑对应的 uniform，色相锁在封面上。
3. 换歌时 uniform 用 400ms 插值，不硬跳。

**这条同时解决了配色问题**：副色调的丰富度由歌决定，不用手配色板；绿仍然是唯一的强调色，变的只有背景。

---

## §5 玻璃真折射 + metaball 进度（`#2e`）

Slint 至今没有 backdrop blur（`docs/slint/visual-effects-and-shaders.md`），所以 Home/Server 那两页的玻璃是"半透明 + 厚度 + 高光"，不会真的模糊背景。**但播放页的玻璃条压在 3D 像素上** —— `crates/render3d/src/glass.rs` 那个 pass 能采样背后的帧：

1. glass pass 采样场景纹理 → 真模糊 + 边缘色散。
2. 进度滑块用 `lead`（快）/ `lag`（慢）两个圆做 smooth-union，拖动时拉出胶着的颈 —— **直接复用 `nav_glass` 的 metaball shader 与省电门**，只换几何来源。
3. 功能层仍然是 2D、不参与遮挡（ADR-0010 不可破坏）。

---

## §6 歌词体积景深（`#2f`）

1. 歌词卡 z 抬到位移峰值之上（现有 `CARD_ANCHOR.z` 已是 1.8），粒子一颗不少、全从字后面走。
2. 前后行按 `|Δz|` 给 **CoC 半径**做真景深，而不是贴一层固定模糊。
3. 换行时 z 插值，字像从远处走上来。

**前提不变**：歌词在别处没有等价路径，被盖住就是读不到，所以永远不能被遮挡。曾经试过让粒子按歌词包围盒绕开 —— 会在点云里横贯一条空带，已回退，别再试。

---

## §7 状态即视觉 · 缓冲 / 断流（`#2g`）

1. **缓冲**：位移场加高频噪声 + 轻微 CoC，像信号不稳。跟着 `audio::SeekState` 的轮询走。
2. **断流**：saturation uniform 3s 降到 0.06，声音停在哪儿画面就冻在哪儿。
3. 错误横幅**降级**成一行小字，不再压在画面正中 —— 状态先被看见，再被读到。

配合 ADR-0013「断流是一种可上报的结束」。文案仍归 `describe_stream_loss`，可见性仍归 `.slint` 里那句 `if banner-text != ""`，`tests/banner.rs` 继续守着。

---

## §8 全局 grain + 扫描线（`#2h`）

1. 全屏后处理：hash 噪声按帧号变，overlay 混合，**强度 0.03–0.06**（再高就脏）。
2. 扫描线 1px 亮 / 3px 暗，亮度 −2%，**只在沉浸层开**，常驻界面不加。
3. 一道极轻的 vignette 收边，把注意力拢回中心。

一个 fullscreen triangle、十几行 WGSL。设计稿 `#2h` 那张卡是左右分屏对比（左关右开），可以照着调强度。

---

## §9 动态极光按钮纹理（`#2i`）

> 这一版是**按文字描述做的猜测**，用户会补参考图，届时按图重做。

- 按钮表面是一小块独立的极光纹理：同一个 shader，每颗按钮不同的 **seed 与转速**（设计稿里是 6s / 9s / 11s / 14s 一圈）。
- 静息态只有约 **12% 的亮度在动**，不抢注意力；hover/按下时幅度提一档。
- 只在**前台且窗口可见**时跑，退到后台走既有省电门。
- 色相取自主绿 + 相邻副色（青、黄绿、紫），**不引入新色相**。
- 设置页有开关（「动态极光按钮」），关掉就是纯色实底，功能完全不变。

---

## 通用约束

- 不新建渲染管线：遮挡复用 render3d 既有的双图设施（场景 + 遮挡层）。
- `preset` 那条 seam 留着（`.slint` 的 `viz-preset` → `VizControls` → `VizFrame` → uniform），当前唯一合法值仍是 0（ADR-0014）。越界兜底也留着 —— 那是跨层信任边界，与档位多少无关。
- 无 GPU 端（web / ios 默认构建）粒子为空图，自动退回 warp 形态；本文件所有效果都必须在这条路径上**静默降级而不是报错**。
