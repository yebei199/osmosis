# app-core/src

客户端领域规则:应用持有的状态,以及改变它的规则。纯规则层 —— 不依赖 slint、
不依赖 `api`/HTTP、不碰时钟与文件系统、不开线程;要时间的地方由调用方把毫秒
传进来,要网络的地方由调用方注入闭包(`docs/adr/0002`)。所以每一条都能不起
窗口、不连服务端地单测。

| 文件 | 管什么 |
|---|---|
| `queue.rs`(+ `queue/tests`) | 队列:当前一首、下一首、洗牌与循环 |
| `playback.rs` | 一首歌的加载与播放状态机,带代际校验 |
| `output.rs` | 输出设备,以及遥控器手上那份被控端上报的镜像(插值、过期、失联) |
| `session.rs` | 播放组会话:选设备 = 迁移当前播放,四步确认与「待确认」(#137 ③) |
| `health.rs` | 服务端健康检查 |
| `lyric.rs` | 歌词按时间取行 |
| `counter.rs` | 示例计数器 |

不在这里的:界面投影(`crates/ui`)、信令与传输(`crates/syncplay`)、线上格式
(`crates/contract`,本 crate 只透传其中几个 DTO)。
