# player

`../player.rs`(`Player`)的私有子模块与测试。对外只有 `Player`,这里的东西不出 crate。

- `deck.rs`:接在混音器上的唯一一路源，管换源、清空与音量(#192)。替掉的是 rodio 的
  `Player`:它每 5ms 在送声回调里阻塞地拿五把控制锁，界面线程调音量、换歌时也拿，
  实时线程因此会等一个被抢走 CPU 的普通线程。这里回调那一侧只做原子读写与 `try_lock`,
  换下来的旧源送回界面线程那边释放，不在回调里析构。换源只在帧边界生效:回调拉到一帧中间时
  换上去的话，新源的左声道落进右声道的槽，整首左右对调(MEO-2193)。
- `tests.rs`:`Player` 与 `Deck` 的单元测试，不开声卡。
